# 1차 제출 구현 순서

목표: 2026-11-14 제출(마감 11/15 23:59). 기준: `docs/decisions-2026-11-11.md`.
순서 원칙: 판단 핵심(테스트 가능) → 데이터 → 화면 → 차량 신호 연결 → 통합 확인 → 제출.
에뮬레이터는 9단계의 통합 확인과 영상 녹화 때만 켠다. 그 전 단계는 JVM 단위 테스트와 Compose Preview로 확인한다.
영상 동작 범위가 회의에서 정해지면 5~8단계의 순서와 범위를 다시 맞춘다.

## P0 (1차 제출 필수)

- [x] 실제 `CarUxRestrictions` 어댑터(release 빌드. debug는 가짜 유지).
- [x] 주행 진입 시 화면 닫기 + 학습 음성 중단 실행.
- [x] 정차 시 "이어서 확인할까요?"(이어 보기 / 처음부터 보기 / 나중에 보기).
- [x] 부록 E 문구(차량 상태 확인 중은 임시 문구로 추가, 불러오기 실패는 4단계 업체 설정 문구, 음성 미지원 → 화면으로 계속은 8단계 주행 안내 음성에서).

- 메모(11/14): 화면 제한 신호는 android.car(`useLibrary` + `uses-library` required=false)로 받는다. Pleos Vehicle SDK 2.3.2에는 화면 제한 API가 없다. "처음부터 보기"는 새 회차를 저장한 뒤 이어 보기(T19·B2)로 보내 첫 카드로 들어간다(상태 머신 변경 없음). 정차 대기에 "교육·퀴즈 열기"(T21)를 두고, 열 수 없는 이유는 차량 스냅샷(`learningAvailability`)이 정한다. 대여 설정 화면은 코드를 바꾸지 않는다: MainActivity를 주행 중 사용 화면(distraction optimized)으로 표시하지 않았으므로 AAOS가 주행 중 가린다(9단계 확인 6). 학습 음성(카드 읽어 주기)은 지원 계획에 있으나 1차 제출에는 넣지 않는다.

- [ ] 부록 A-8·E 원문으로 안내 문장 임시 문구 교체.
- 메모(11/14): 주행 중 규칙 상기는 B11(기어 D/R일 때만). 위치는 debug·release 모두 실제 FusedLocation, 10초 넘은 위치는 버린다. 안내 문장은 strings.xml 문구 ID(한국어 기본, 영어 values-en)를 대여 언어로 읽는다. 음성은 영어만(Pleos TTS), 한국어 대여는 heads-up 알림 문장으로(부록 E). 주정차 경고는 언어와 상관없이 알림도 띄운다. "처음 만남"은 대여 단위로 세고 반납(T5) 때 초기화(메모리만). T13은 P로 바꾼 순간에만 판단(state-machine.md "가드 해석 보완 2026-11-14").

### 9단계. 통합 확인과 공통 시험 (11/13 밤)
- [x] 에뮬레이터 확인 1: 어댑터(UX 제한, TTS, 위치)가 Coordinator까지 들어오는가.
- [x] 에뮬레이터 확인 2: 내비 위 알림, 주행 시 교육 화면 닫힘, 정차 시 이어 보기.
- [ ] 공통 시험 6종: 중복, 만료, 경로 변경, 내비·통화 충돌, UX 제한, 반납 후 삭제.
- [x] 에뮬레이터 확인 3: 앱을 껐다 켜도 대여·교육 진행·관리자 코드가 남는가(DataStore).
- [ ] 에뮬레이터 확인 4: 클라우드 백업·기기 이전에서 앱 데이터가 빠지는가.
- [x] 에뮬레이터 확인 5: 앱을 켜면 권한 요청 뒤 상주 알림(주행 안내)이 뜨는가. 위치 권한을 거부하면 서비스가 시작되지 않고 안내 문구가 보이는가.
- [x] 에뮬레이터 확인 6: 점검 화면에서 출발하면 시스템(UX 제한)이 화면을 가리는가, 정차하면 점검을 이어서 마칠 수 있는가.
- 메모(11/14): 에뮬레이터(user 빌드)에서 확인 2·3·5를 마쳤다. 확인 1은 위치(주정차 구역 경고)와 release의 실제 화면 제한 신호(정차 중 제한 없음 → 교육 열림)까지 확인했고, TTS는 언어 전달과 재생 완료 로그까지만 확인했다(소리는 듣지 못함). 확인 4는 에뮬레이터에 백업 서비스가 없어 설정 파일로만 확인했다. 확인 6과 주행 중 실제 화면 제한은 adb로 차량 신호를 넣을 수 없어 실차나 에뮬레이터 차량 데이터 화면에서 확인해야 한다. 공통 시험 중 "반납 후 삭제"는 에뮬레이터에서, 나머지는 단위 테스트로 확인했다. release는 기어·차속이 가짜(P, 0)라 주행 안내와 주정차 경고가 나오지 않고, 운전석 착좌는 앉음으로 고정해 반납 뒤 다음 대여는 앱을 다시 켜야 시작된다. release 최적화 범위에 `kotlin.**`이 있으면 앱이 시작하자마자 멈춰(R8, IllegalAccessError) 11/14 승인으로 범위에서 뺐다(172ff3d).
- 메모(11/15): release가 기어·차속·운전석 착좌·안전띠를 실제 신호로 받게 바꿨다(76d6020). 위 메모의 "기어·차속 가짜, 착좌 앉음 고정"은 더 이상 맞지 않는다. Pleos 가상 콘솔(포트 8088)로 주행 진입 시 교육 화면 닫힘, 정차 시 주정차 경고와 음성, 통화 중에는 음성 없이 알림만(536eb27), 반납 뒤 운전석 비움 → 앉음으로 앱을 다시 켜지 않고 다음 대여 시작을 확인했다. SDK 착좌 값은 표준 원값과 반대라 뒤집어 읽는다(에뮬레이터 기준, 실차 확인 필요). 안전띠는 콘솔에 좌석별 경고가 없어 연결만 하고 확인하지 못했다. 차속 권한을 거부하면 정차·주행을 알 수 없다.
